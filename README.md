## 💡 能解决什么问题？

1. **识别假文献与幻觉引用**：检测大模型（ChatGPT/DeepSeek）撰写综述时凭空捏造的不存在文献。
2. **排查撤稿论文 (Retraction Watch)**：自动标记被撤稿（Retracted）论文，避免学术引用风险。
3. **Crossref DOI 秒级核验**：一键校验卷期页码、作者排序与出版年份是否真实准确。
4. **期刊影响因子与中科院分区提示**：自动补齐目标期刊的最新影响因子与分区等级。
